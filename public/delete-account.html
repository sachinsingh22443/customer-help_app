Delete Account Request

Users can permanently delete their Eat Unity account from within the app.

Steps

  1. Login to Eat Unity
  2. Open Profile → Delete Account
  3. Select a reason
  4. Type DELETE
  5. Confirm account deletion

Data Deleted

  • Profile information
  • Phone number
  • Saved addresses
  • Order history
  • Subscription information
